# Synthetic AI asset packages

All packages in this folder are demonstration content for a local proof of concept.
Names, teams, owners, evidence, approvals, and service locations are fictional.
They do not represent NIH/NCI policies, deployed integrations, or authorizations.
Remote URLs use the reserved `.invalid` namespace. No credentials are included.

Each asset folder includes its source (`server.json` or `SKILL.md`) and a readable
package README. The app exposes these same files for source inspection/download.

Scenario: November 2, 2026. Four assets start approved and four await review.
MCP servers are the primary governance workflow; agent skills are a secondary
asset type. The Lab Workspace File Index MCP is ready for a four-part reviewer
attestation and scoped approval demo. The clinical export connector is
deliberately blocked. A literature brief skill provides a secondary approval example.
