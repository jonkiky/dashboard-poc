# Lab Workspace File Index — demonstration package

This is a review-ready, synthetic MCP package for the local governance proof of concept.
No real endpoint, credential, researcher, team, or NIH/NCI approval is represented.

- Asset ID: `mcp-labfiles`
- Version: `0.1.0`
- Format: `server.json`
- Status: In review; no approval is implied by passing automated checks.
- Intended demonstration: Inspect synthetic laboratory workspace file metadata for research organization and reproducibility planning.
- Data classification: Internal
- Environment: Research sandbox
- Declared action: `read:file-metadata`
- Destination boundary: internal network scenario

Four passing synthetic evidence records cover security, privacy, validation, and ownership.
A reviewer must still complete all four attestations and record a named decision.
The approved scenario, if granted, remains limited to this version and scope.

File contents, unrestricted paths, writes, code execution, and exports are outside
this package's declared scope. The endpoint and schema URLs use the reserved
`.invalid` namespace and do not identify working integrations. The local app
simulates all operations and must never receive actual sensitive research data.

Approval records are local simulation records. They do not authorize use in any
government or research system or establish compliance with NIH/NCI policy.
