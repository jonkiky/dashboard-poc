# Clinical Cohort Export Connector — demonstration package

This is an illustrative, synthetic package for the local governance proof of concept.
No real endpoint, credential, researcher, team, or NIH/NCI approval is represented.

- Asset ID: `mcp-clinical`
- Version: `0.3.0`
- Format: `server.json`
- Intended demonstration: Demonstrate a blocked request to export controlled cohort records outside the approved boundary.
- Data classification in the scenario: Controlled
- Environment in the scenario: Research sandbox
- Declared actions: read:records, export:cohort

Inspect `server.json` to review the package metadata or instructions. Remote URLs use
the reserved `.invalid` namespace and do not identify working integrations.

Approval records in the app apply to the exact scenario and version. They are local
simulation records and do not authorize use in any government or research system.
